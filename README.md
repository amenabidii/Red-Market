Red Market is a narrative simulation game where players face the same high-pressure choices I did. It challenges you to balance financial greed against mental health and real-world emergencies.

Key Features:

Branching Narrative: 20+ unique scenarios with multiple endings ranging from "Total Loss" to "Safe Exit."

Immersive Design: I used Tailwind CSS to create a modern, app-like interface that reacts to the player's emotional state.

Dynamic Visuals: The game features custom AI-generated artwork that shifts the mood from hopeful to desperate based on your portfolio performance.

Building this allowed me to practice front-end web development while exploring how interactive media can be used for storytelling.
